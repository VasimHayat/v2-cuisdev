## A JSON editor built like a desktop tool

Most online JSON editors are a text box with a Format button. This one is a workspace. The code pane is a full editor with folding, search and replace, multiple cursors and live error underlining. The tree pane is interactive: expand and collapse, filter by key or value, edit a value in place, delete a node, copy its path. Split view shows both at once and keeps them in sync, and the Output view gives you a read-only formatted or compacted copy ready to copy or download.

Everything runs in your browser. That is why there is no upload progress bar, no file size plan and no waiting.

## Finding and fixing errors

JSON has a small, strict grammar and a single stray character breaks the whole document. The editor parses as you type and shows the first problem as a red banner with the line, the column, what went wrong and, for the common mistakes, how to fix it. Click the banner to jump to the character.

For the usual culprits there is a one-click Fix. It removes comments, swaps single quotes for double quotes, quotes bare keys, removes trailing commas and replaces JavaScript-only values such as `undefined` with `null`. It is conservative and never touches text inside a valid string, so it is safe to run on real data. If a document is too broken for a mechanical fix, Fix with AI sends it to Gemini with your own key and asks for the minimal correction.

## Common JSON errors and what they mean

- **Unexpected token } or ]** usually means a trailing comma after the last property or item.
- **Unexpected token '** means single quotes. JSON strings and keys must use double quotes.
- **Expected a quoted property name** means an unquoted key, such as `{name: "x"}`.
- **Unexpected end of input** means the document stops early. A closing `}` or `]` is missing.
- **Unexpected token /** means a comment. Strict JSON has no comments.

## Working with large documents

Drop a 20 MB export onto the editor and it opens in a moment. The code pane virtualises rendering so scrolling stays smooth, and folding lets you collapse the parts you are not looking at. The tree pane renders the first 5,000 nodes, and the filter box narrows thousands of records to the ones that contain a term. Expand all and Collapse all work on whatever is visible.

## Sharing and saving

Share copies a link with the document compressed into the URL fragment. Browsers never send the fragment to a server, so the data travels only between you and the person you send it to. Links are limited to roughly 12 KB of compressed JSON; for anything bigger, Save downloads a .json file. Your current draft is also kept in this browser's local storage so a refresh or an accidental tab close costs nothing.
