## Realistic test data without writing a script

Every front end, test suite and demo needs data before the real data exists. Hand-writing a JSON fixture is slow and the result looks fake; writing a script with a data library takes longer than the task deserves. A template is the middle ground: write the JSON shape you want once, mark the values with placeholders, and get as many realistic records as you need.

The template is plain JSON, so it doubles as documentation of the structure. Keys, nesting and literal values pass through unchanged; only the placeholders are replaced.

## How templates work

A placeholder is a name in double braces, optionally with arguments, such as `{{number.int(1,100)}}` or `{{pick(draft,published,archived)}}`. When a placeholder is the whole string value, the generated value keeps its type, so `"{{boolean(0.8)}}"` becomes `true` or `false` rather than text. Placeholders inside longer strings are written as text, which is how you build values like `"Order {{index(1)}} for {{name.first}}"`.

Arrays become lists with a repeat marker as their first element. `["{{repeat(20)}}", { ... }]` produces twenty objects, and repeats can be nested to any depth. The Records box overrides the top-level count without editing the template. To protect your browser, a template that would generate more than 50,000 items stops with a message.

| Placeholder | Example output |
| --- | --- |
| `{{name.full}}` | Priya Sharma |
| `{{internet.email}}` | lars.nielsen@example.org |
| `{{number.float(0,1,3)}}` | 0.417 |
| `{{date.past(2)}}` | 2025-06-11T08:42:19.000Z |
| `{{uuid}}` | 3f2b9c1e-8a4d-4f6b-9c2e-1d7a5b8e0f34 |
