## How PDF compression works in a browser

Most of a PDF's size comes from images: scanned pages, photographs and screenshots embedded at full resolution. Text and vector drawings take up very little room. Shrinking a PDF is therefore mostly about images, and how much can be saved depends on what the file contains.

Optimise copies every page into a freshly written document. Anything the pages no longer reference, such as leftovers from earlier edits, duplicated resources or orphaned images, is left behind, and the file is written with compressed object streams. Because page content is copied as it is, the result looks and behaves exactly like the original. On clean, text-based PDFs the saving is small, and the tool says so.

## When to use Compress images

Compress images renders each page with pdf.js at the resolution you choose and stores it as a JPEG, then builds a new PDF with one image per page at the original page size. For scanned contracts, photographed receipts and image-heavy brochures this routinely cuts the size by more than half. The trade-off is that every page becomes a picture, so the side-by-side preview of page 1 lets you judge legibility before you download.
