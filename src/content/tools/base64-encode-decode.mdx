## Base64 in plain terms

Base64 is a way of writing bytes as text. Every 3 bytes become 4 characters drawn from A to Z, a to z, 0 to 9, plus and slash, with equals signs padding the end. The result survives any system that handles text, which is why email, JSON, HTML data URLs and HTTP headers all lean on it. It is not encryption and it is not compression; it makes data a third larger and hides nothing.

This tool handles the everyday cases: a string that needs to go into a header, a token that needs to be read, an image that needs to become a data URL, and a data URL that needs to become a file again. It understands both the standard and the URL-safe alphabets, forgives missing padding and line breaks, and tells you when the decoded bytes are binary rather than text.

## Files and data URLs

Drop a file onto the input pane to encode its bytes. Turn on Data URL and the output is prefixed with the file's MIME type, ready to paste into an `src` attribute or a CSS `url()`. Going the other way, paste a data URL and the tool strips the prefix, decodes the payload, previews it if it is an image and offers it as a download with a sensible extension.
