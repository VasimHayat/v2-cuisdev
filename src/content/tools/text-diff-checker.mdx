## What a diff shows

A diff shows what changed between two versions of a text: which lines were added, which were removed and which were edited. Developers use it to review a change before committing it, writers use it to spot edits in a revised draft, and anyone can use it to answer "what is different between these two files?" without reading both line by line.

This checker aligns the two texts with the same algorithm git uses, then looks inside each changed line to mark the exact words or characters that differ. A one-character typo therefore looks like a one-character change, not a whole rewritten line.

## Reading the two views

Side by side puts the original on the left and the changed text on the right, with each line's own number. Lines that exist on only one side leave a blank on the other, so the two columns stay aligned and you can read down either one. This is the view to use when both versions matter, such as reviewing an edit to a document.

Inline stacks the removed lines above the added lines, prefixed with minus and plus signs, in the same order a unified patch uses. It is narrower, so it suits long lines and small screens, and it is the view to use when you only care about what the new version looks like.

Only changes hides every run of unchanged lines longer than six, keeping three lines of context on each side of a change. A collapsed run shows how many lines it hides and expands with a click, the same way a code review tool does.

## Exporting the result

Copy diff and Download produce a unified diff. It starts with the two file headers, then one hunk per group of changes, each introduced by an `@@` line that gives the starting line and length on both sides. A hunk contains context lines prefixed with a space, removed lines prefixed with a minus and added lines prefixed with a plus.

Because this is the format every version control system understands, you can save it as a patch file and apply it elsewhere with `git apply changes.diff` or `patch -p1 < changes.diff`, or paste it into a ticket so a colleague sees the exact change.
