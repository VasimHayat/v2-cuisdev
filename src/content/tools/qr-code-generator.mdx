## What a QR code holds

A QR code is a grid of dark and light squares, called modules, that encodes a short piece of text. Phones decide what to do from that text: a web address opens the browser, a `WIFI:` string offers to join a network, a `mailto:` link starts an email, and a vCard adds a contact. This generator builds the right text for each type, shows it to you, and then draws the code.

Three large squares in the corners let a camera find and align the code, and the rest carries your data plus error correction. Larger content needs more modules, so the code moves up through versions from 21 by 21 modules to 177 by 177. Short content scans more reliably, which is why a short web address beats a long one with tracking parameters.

## Styling without breaking it

Colours, rounded or dotted modules and a centre logo can make a code fit a brand, but every change costs some reliability. The corner markers are always drawn as solid shapes so cameras can still lock on, a contrast check flags colours that are too close, and a logo automatically raises error correction and is size-capped. A plain dark code on a light background with a generous quiet zone remains the most dependable choice for anything printed.
