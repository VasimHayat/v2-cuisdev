## Put pages in the right order

Scanned documents rarely come out in the right order. Pages get fed in backwards, an appendix ends up in the middle, or a page is scanned sideways. This tool shows every page as a thumbnail so you can see the whole document at once, drag pages to where they belong, turn the sideways ones upright and remove blanks, then save a clean copy.

Selection works the way it does in a file manager. Click a page to select it, Shift-click to extend the selection to a range, and Ctrl-click to add or remove single pages. Drag any selected page and the whole selection moves together, keeping its internal order. Each page shows its original number once it has moved, so it is easy to check the result against the source.

## Keyboard and undo

Everything can be done without a mouse. Arrow keys move between pages, Space selects, Ctrl plus an arrow moves the selection, R rotates and Delete removes. Every action can be undone and redone, so it is safe to experiment, and the original file on your disk is never modified.
