## Write Markdown, see the result

Markdown is the plain-text format behind README files, documentation sites, chat messages and many note-taking apps. It is quick to write but easy to get slightly wrong: a missing blank line merges two paragraphs, a table separator row with the wrong number of cells breaks the whole table. A live preview catches those mistakes as you make them.

The editor keeps your text on the left and the rendered page on the right. The toolbar wraps whatever you have selected, so formatting an existing sentence is one click, and pressing the same button again removes the formatting.

## Safe by default

Markdown allows raw HTML, which means a document pasted from an untrusted source can contain scripts. Everything this tool renders goes through DOMPurify, a widely used HTML sanitiser, before it reaches the page. Dangerous tags and attributes are stripped, unsafe link schemes are removed, and every remaining external link opens in a new tab without access to this page. The HTML you copy or download is the same cleaned markup.
