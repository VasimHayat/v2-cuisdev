## Bases in everyday programming

Computers store everything in binary, but people read decimal, and programmers read hexadecimal because each hex digit maps to exactly four bits. Octal survives in Unix file permissions. Converting between them comes up constantly: reading a memory address, decoding a flags field, checking a colour channel, or working out why a bitmask does not match. This converter keeps all the bases side by side, so you can type in whichever one you have.

Values are held exactly with arbitrary-precision integers, so there is no rounding at 2 to the power 53 as there is with ordinary JavaScript numbers. A 256-bit hash in hex converts to decimal and back without losing a digit.

## Signed numbers and bits

Turn on Signed to work with two's complement, the representation almost every processor uses for negative integers. The width matters: FF is -1 as a signed 8-bit value but 255 as a 16-bit one. The bit grid shows the pattern for the chosen width with the sign bit first, and clicking a bit flips it, which is a fast way to build or check a bitmask.

Fractions are exact too. Type 0.1 in the decimal field and the binary field shows 0.0(0011), with the repeating block in parentheses. That one line explains most floating-point surprises.
